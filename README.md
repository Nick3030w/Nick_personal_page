## ⚙️ Instalación local

Sigue estos pasos para correr el proyecto en tu máquina:

**1. Clona el repositorio**
```bash
git clone https://github.com/Nick3030w/Nick_personal_page.git
cd Nick_personal_page
```

**2. Instala las dependencias**
```bash
npm install
```

**3. Inicia el servidor**
```bash
node app.js
```

**4. Abre en tu navegador**
```
http://localhost:3000
```

## 🚀 Despliegue

El proyecto está desplegado en **Railway**. Cada push a la rama `main` puede configurarse para hacer deploy automático.

Si quieres desplegarlo tú mismo:
1. Crea una cuenta en [Railway](https://railway.app)
2. Conecta tu repositorio de GitHub
3. Railway detecta automáticamente que es un proyecto Node.js y lo despliega
